# Final Assignment - Data Structures Course (UFLA)

This project is the final work for the Data Structures course at the Federal University of Lavras (UFLA), developed in C++.

The program implements a basic sequence set structure using binary files to store records. It allows the user to insert, search, remove, and display records organized by ID, simulating a file-based index system.

## English version

### Project purpose

The main goal of this assignment is to apply the fundamental concepts of data structures, such as:

- ordered insertion
- binary search
- sequence set organization
- file manipulation in binary format
- record management in dynamic nodes

### Features

- import records from CSV files
- insert new records through the terminal
- search records by ID
- remove records by ID
- show all stored records
- store records in binary files generated by the program

### Main files

- `teste.cpp` — main source code of the project
- `regs.csv` — sample input data file

### Compilation

Use a C++ compiler such as `g++`:

```bash
g++ teste.cpp -o teste
./teste
```

### How it works

The program uses a `SequenceSet` structure composed of nodes, where each node contains a binary file and a fixed-size array of records. Records are organized in order, and operations are performed by reading and writing to these files.

This project demonstrates the use of data structures in a practical way and is intended as a final evaluation of the course.

# Trabalho Final - Disciplina de Estrutura de Dados (UFLA)

Este projeto é o trabalho final da disciplina de Estrutura de Dados da Universidade Federal de Lavras (UFLA), desenvolvido em C++.

O programa implementa uma estrutura de conjunto em sequência utilizando arquivos binários para armazenar registros. Ele permite ao usuário inserir, buscar, remover e exibir registros organizados por ID, simulando um sistema de gerenciamento baseado em arquivos.

## Versão em português

### Objetivo do projeto

O objetivo principal deste trabalho é aplicar conceitos fundamentais de estrutura de dados, como:

- inserção ordenada
- busca binária
- organização de conjunto em sequência
- manipulação de arquivos em formato binário
- gerenciamento de registros em nós dinâmicos

### Funcionalidades

- importação de registros a partir de arquivos CSV
- inserção de novos registros pelo terminal
- busca de registros por ID
- remoção de registros por ID
- exibição de todos os registros armazenados
- armazenamento dos registros em arquivos binários gerados pelo programa

### Arquivos principais

- `teste.cpp` — código-fonte principal do projeto
- `regs.csv` — arquivo de dados de exemplo

### Compilação

Use um compilador de C++ como o `g++`:

```bash
g++ teste.cpp -o teste
./teste
```

### Como funciona

O programa utiliza a estrutura `SequenceSet`, composta por nós, em que cada nó contém um arquivo binário e um vetor de registros de tamanho fixo. Os registros são organizados em ordem, e as operações são realizadas lendo e escrevendo nesses arquivos.

Este projeto demonstra a aplicação prática de estruturas de dados e foi desenvolvido como avaliação final da disciplina.
